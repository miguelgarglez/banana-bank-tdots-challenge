# Does Cloud have a fee?

Document faq-cloud-account. Version 2. Effective from 2026-09-01. Audience: customers. Banana Bank is a simulated bank: this document describes only the policies of the test environment, in euros. Balances and movements come from the customer's bank ledger, never from this document.

## Answer

The Cloud monthly fee is EUR 0. This applies only to Cloud, not to other products.
