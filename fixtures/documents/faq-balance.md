# Where can I check my balance?

Document faq-balance. Version 2. Effective from 2026-09-01. Audience: customers. Banana Bank is a simulated bank: this document describes only the policies of the test environment, in euros. Balances and movements come from the customer's bank ledger, never from this document.

## Answer

The current balance comes from the banking API and is shown in the Overview. A previous conversation or a commercial document never contains your current balance.
