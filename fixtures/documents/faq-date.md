# Which date does the corpus use?

Document faq-date. Version 2. Effective from 2026-09-01. Audience: customers. Banana Bank is a simulated bank: this document describes only the policies of the test environment, in euros. Balances and movements come from the customer's bank ledger, never from this document.

## Answer

The reference date of the documentation is September 24, 2026. Changes with a later effective date do not apply before that date.
