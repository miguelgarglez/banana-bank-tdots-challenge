# How do I choose a source account?

Document faq-two-accounts. Version 2. Effective from 2026-09-01. Audience: customers. Banana Bank is a simulated bank: this document describes only the policies of the test environment, in euros. Balances and movements come from the customer's bank ledger, never from this document.

## Answer

If you have several accounts and did not specify one, the assistant asks which one to use. It never chooses one by default or by alphabetical order.
