# What is the reference for?

Document faq-reference. Version 2. Effective from 2026-09-01. Audience: customers. Banana Bank is a simulated bank: this document describes only the policies of the test environment, in euros. Balances and movements come from the customer's bank ledger, never from this document.

## Answer

It identifies one logical intent. Retrying the same intent keeps the same reference, so the bank never executes it twice. A different desired transfer, even with the same recipient and amount, needs a different reference.
